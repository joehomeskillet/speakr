# Tastatur im Schreibplatz

[English](../../user-guide/keyboard-shortcuts.md) · Deutsch

Öffnen Sie ein bearbeitbares Diktat im **Schreibplatz**. Setzen Sie den Fokus ins Dokument. **F1** oder die Schaltfläche **Tastaturhilfe** zeigt die Befehle. Unter macOS verwenden Sie **Cmd** anstelle von **Strg**.

| Aktion | Tasten |
|---|---|
| Aktuelle Korrektur speichern | Strg+S |
| Textänderung rückgängig machen / wiederholen | Strg+Z / Strg+Umschalt+Z |
| Absatz einfügen | Strg+Enter |
| Im Transkript suchen | Strg+F |
| Nächster / vorheriger Treffer im Suchfeld | Enter / Umschalt+Enter |
| Vollbildmodus des Editors umschalten | Strg+Umschalt+F |

In den Diktatdetails erreichen Sie die Wiedergabeschaltfläche mit Tab und starten oder pausieren mit Enter. Über die fokussierte Zeitleiste springen Sie im Audio. Einen Kontextdialog schließen Sie mit Escape oder der sichtbaren Schaltfläche. Der Fokus kehrt zum Auslöser zurück. Schreibbefehle benötigen einen bearbeitbaren Schreibplatz. Text-Undo und das Rückgängigmachen eines Audioschnitts sind getrennt.

Ein Fußpedal im Tastaturmodus sendet Tasten an den fokussierten Browser. Die Zuordnung finden Sie in den [Arbeitsplatzeinstellungen](settings.md). Systemweite Tastenkürzel in anderen Anwendungen gehören nicht zum Webclient.
