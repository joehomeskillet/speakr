# Das Diktat zu einer Frage finden

[English](../../user-guide/inquire-mode.md) · Deutsch

„Ask Ambrose“ stellt in der Originalversion Fragen über mehrere indizierte Aufnahmen. Die Suche unter **Aufnahmen** durchsucht die Metadaten der für Ihr Konto geladenen Zeilen.

1. Öffnen Sie **Aufnahmen** und wählen Sie bei Bedarf Zeitraum oder Verarbeitungsstatus.
2. Suchen Sie nach diktierender Person, Schreibkräfte-Pool, Fall-ID oder Diktat-ID. Laden Sie weitere Zeilen, falls die Liste weitere Ergebnisse anbietet. Gesprochene Wörter erfasst diese Suche nicht.
3. Öffnen Sie den Treffer, prüfen Sie den Fall und hören Sie die Passage unter **Diktat anhören** ab. Im bearbeitbaren Transkript finden Sie ein Wort über die Suche im **Schreibplatz**.

Eine leere Suche kann an einem Filter, einer noch ungeladenen Zeile oder der Berechtigung liegen. Die Poolverwaltung kann die Zuordnung prüfen. Ein Suchtreffer erweitert weder die fallbezogene Sicht noch die Wiedergaberechte.
