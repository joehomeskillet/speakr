# Erste Schritte

[English](../../user-guide/first-steps.md) · Deutsch

1. Öffnen Sie die Adresse Ihrer Klinik im Browser und melden Sie sich mit dem zugewiesenen Konto an. Bei Anmeldeproblemen hilft die Kontoverwaltung Ihrer Einrichtung.
2. Öffnen Sie **Aufnahmen**. Schränken Sie die Liste nach Status und Zeitraum ein. Die Suche findet diktierende Person, Pool, Fall-ID oder Diktat-ID in den **bereits geladenen Zeilen**. Laden Sie bei Bedarf weitere Aufnahmen.
3. Wählen Sie das Diktat. Prüfen Sie unter **Diktatdetails** die Angaben **Diktiert von**, **Schreibkräfte-Pool** und, falls vorhanden, **Fall-ID**. Mit dem Abspielrecht können Sie unter **Diktat anhören** die aktuelle Audiofassung starten und pausieren.
4. Zum Bearbeiten wählen Sie **Im Schreibplatz öffnen**, sofern Ihr Konto bearbeiten darf. Zugewiesene Aufträge finden Sie in der **Arbeitsliste**. Die Details trennen Verarbeitung, Arbeitsstand, Abnahme und Ausgabe.

Für die erste Probe eignet sich ein neutraler Titel. Folgen Sie der [Anleitung zur Aufnahme](recording.md). Bei einer leeren Liste setzen Sie zunächst die Filter zurück. Die Verwaltung kann anschließend Konto und Zuordnung prüfen.
