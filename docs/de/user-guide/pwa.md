# Speakr als Browser-App verwenden

[English](../../user-guide/pwa.md) · Deutsch

Öffnen Sie die HTTPS-Adresse Ihrer Klinik im unterstützten Browser. Bietet dieser **App installieren** oder **Zum Home-Bildschirm** an, können Sie die Funktion gemäß Arbeitsplatzvorgabe nutzen. Das Symbol öffnet dieselbe Klinikseite mit der üblichen Anmeldung. Die Mikrofonfreigabe erfolgt separat für die Website.

Bei unterbrochener Übertragung oder Speicherung öffnen Sie im Kopfbereich **Verbindungsstatus / Entwürfe**. Der Service Worker speichert statische Oberflächendateien zwischen. Klinikaudio, Diktate, API-Antworten und Kontoseiten werden von diesem Cache ausgeschlossen. Über das installierte Symbol entsteht keine Offlinekopie des Diktats.

Die reguläre Klinikansicht bietet derzeit keine dauerhafte Wiederherstellung lokal aufgenommener Audioentwürfe. Prüfen Sie nach Wiederverbindung den vom Server bestätigten Stand, bevor Sie erneut einreichen. Behalten Sie eine hochzuladende Originaldatei bis zur Quittung. Melden Sie sich an gemeinsam genutzten Arbeitsplätzen ab. Erscheint nach einer Aktualisierung eine alte Oberfläche, laden Sie den Tab zunächst normal neu.
