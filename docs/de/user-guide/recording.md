# Aufnehmen, hochladen und einreichen

[English](../../user-guide/recording.md) · Deutsch

## Im Browser aufnehmen

1. Wählen Sie **Neue Aufnahme → Aufnehmen** und geben Sie einen **Titel** ein. **Diktiert von** zeigt das angemeldete Konto.
2. Wählen Sie **Aufnahme starten**. Erlauben Sie beim ersten Mal den Mikrofonzugriff für diese Klinikadresse. Mit **Pausieren** unterbrechen Sie die Aufnahme, mit **Fortsetzen** nehmen Sie weiter auf.
3. Wählen Sie **Aufnahme beenden**. Über **Abspielen** können Sie vor der Übertragung probehören. Zu diesem Zeitpunkt ist die Aufnahme noch ungesichert.
4. Wählen Sie **Entwurf sichern** und warten Sie auf die Bestätigung. Mit **Einreichen** geben Sie das gesicherte Diktat an den Schreibdienst weiter. Warten Sie auf **Eingereicht**, bevor Sie die Seite verlassen.

## Vorhandene Audiodatei verwenden

Unter **Neue Aufnahme → Datei hochladen** wählen Sie eine nicht leere Audiodatei über den Dateidialog. Sichern und reichen Sie sie wie oben beschrieben ein. Behalten Sie die Quelldatei bis zur Uploadbestätigung. Schlägt das Sichern fehl, verwenden Sie den Wiederholungsweg im bestehenden Formular. Startet das Mikrofon nicht, prüfen Sie die Browserfreigabe für diese Website und das gewählte Eingabegerät.

Unter **Aufnahmen** sehen Sie den Fortschritt der lokalen Erkennung. Die geöffnete Liste aktualisiert sich bei laufender Verarbeitung. Live-Erkennung während des Sprechens und stimmgesteuerte Aufnahme sind gesonderte Funktionen. Für den nutzbaren Ablauf nehmen Sie zuerst auf und [prüfen die Abschrift danach](transcripts.md).
