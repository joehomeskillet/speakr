# Textbausteine und Dokumentvorlagen

[English](../../user-guide/transcript-templates.md) · Deutsch

Öffnen Sie im bearbeitbaren **Schreibplatz** den Befehl **Textbaustein einfügen**. Wählen Sie eine sichtbare Ressource und prüfen Sie Name, Version und etwaige Hinweise zur Einfügemarke. Die Auswahl zeigt die gewählte Vorlage in dieser Ansicht. Der Vorlagentext wird dabei nicht in die Abschrift eingesetzt. Benötigen Sie eine Überschrift oder Phrase, geben Sie den freigegebenen Wortlaut selbst ein, vergleichen ihn mit dem Audio und speichern.

Berechtigte Administratoren können unter **Verwaltung & Seiten → Sprachbefehle und Vorlagen → Vorlagen** zentral gespeicherte Versionen, Zuordnungen und die Vorschau der Einfügemarke prüfen. Klären Sie einen Hinweis zur Marke vor dem Einsatz. Fehlt eine erwartete Ressource, wenden Sie sich an die für Ihren Pool zuständige Person.

Die „Transcript Templates“ der Originalversion formatieren Transkriptexporte. Die Klinik verwaltet Dokumentvorlagen mit eigener Version und Zuordnung. Die aktuelle DOCX-Ausgabe des freigegebenen Kliniktexts bietet keine Auswahl einer gespeicherten Vorlage oder Textmarke.
