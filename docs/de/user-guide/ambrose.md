# Ambrose und das einzelne Diktat

[English](../../user-guide/ambrose.md) · Deutsch

Ambrose heißt der Assistent in der Originalversion von Speakr. Um eine Aussage im Klinikablauf zu prüfen, beginnen Sie beim zugehörigen Diktat.

1. Öffnen Sie den berechtigten Eintrag unter **Aufnahmen** und kontrollieren Sie diktierende Person und Fallkontext.
2. Hören Sie die Passage unter **Diktat anhören** ab. Mit Bearbeitungsrecht können Sie **Im Schreibplatz öffnen** wählen und den erkannten Wortlaut mit dem Audio vergleichen.
3. Speichern Sie eine fachliche Korrektur im **Schreibplatz** und prüfen Sie den **Verlauf**. Ein generierter Text oder eine Chatantwort löst weder die Korrektur noch die Freigabe aus.

Welche lokalen KI-Funktionen verfügbar sind, hängt vom Klinikbetrieb ab. Der reguläre Diktatablauf setzt keinen Assistentenchat voraus. Wenn Sie die Aufnahme zu einer Frage erst ermitteln müssen, hilft die [Suche in der Aufnahmenliste](inquire-mode.md).
