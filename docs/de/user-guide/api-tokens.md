# Anmeldung für Benutzer und Importagenten

[English](../../user-guide/api-tokens.md) · Deutsch

Für die normale Arbeit melden Sie sich im Klinik-Webclient an. Die Sitzung identifiziert die Person, die ein Diktat erstellt, korrigiert oder prüft. Persönliche API-Tokens aus dem Speakr-Originalhandbuch gehören nicht zum Klinikablauf.

**Sie möchten eine Datei hochladen?** Wählen Sie **Neue Aufnahme → Datei hochladen** und anschließend **Entwurf sichern**. Der Entwurf gehört zum angemeldeten Autor. Mit **Einreichen** übergeben Sie ihn an den Schreibdienst.

**Sie möchten ein zugelassenes Importgerät anbinden?** Die Betriebsverantwortlichen registrieren den separaten Windows-Importer und seine erlaubten Quellen. Der Agent meldet sich über seinen eigenen Kanal am vertrauenswürdigen Eingang an. Geräteidentität und Importquittung erteilen kein Abspielrecht und bestimmen für sich allein keinen Diktatautor. Ungeklärte Importe können über **Dateien und Geräteimport** geprüft werden.

Bei einem abgewiesenen Browserzugriff prüfen Sie Anmeldung und Objektberechtigung. Übernehmen Sie Sitzungscookies oder Zugangstokens niemals in einen Link, Screenshot oder eine Nachricht. [Klinik-API-Referenz](api-reference.md).
