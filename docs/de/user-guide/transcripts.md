# Abhören, korrigieren und prüfen

[English](../../user-guide/transcripts.md) · Deutsch

Öffnen Sie die Diktatdetails und wählen Sie **Diktat anhören**. Starten Sie die Wiedergabe und springen Sie in der Wellenform zur gewünschten Stelle. Fehlen die Wellendaten, bedienen Sie das Audio über die Browserelemente. Beide Wege geben die aktuelle Audiofassung wieder. Mit Abspielrecht können Sie auch zuhören, während eine andere Person die Bearbeitungssperre hält.

## Eine Passage korrigieren

1. Wählen Sie **Im Schreibplatz öffnen**. Kontrollieren Sie Titel und Bearbeitungsstatus, bevor Sie schreiben. Eine aktive Sperre einer anderen Person verhindert die gleichzeitige Bearbeitung.
2. Vergleichen Sie die Passage mit dem Audio. Bei vorhandenen Wortzeiten hebt der Player den zugehörigen Text hervor. Neu eingefügte Wörter und stark umformulierte Passagen können ohne verlässliche Zeitzuordnung bleiben.
3. Korrigieren Sie den Text, wählen Sie **Speichern** und warten Sie auf die Bestätigung. Bei einer zwischenzeitlich neueren Fassung vergleichen Sie die Texte, bevor Sie einen Stand übernehmen.
4. Unter **Verlauf** sehen Sie die entstandene Fassung. Bei entsprechender Berechtigung erzeugen Kürzen, Einfügen oder Überschreiben eine neue Audiofassung. Eine erneute Erkennung verarbeitet den aktuellen Schnitt. Original und menschliche Korrekturen bleiben in der Versionsgeschichte erhalten.

**Prüfen und Freigeben** ist eine eigene fachliche Entscheidung. Prüfen Sie dort aktuellen Text, Audio und Fallkontext. Der Abschluss der Erkennung allein gibt kein Dokument frei.
