# Autorenpools und Schreibteams

[English](../../admin-guide/group-management.md)

Unter **Verwaltung → Konten und Pools** finden Sie die fachliche Zuordnung. Ein **Autorenpool** fasst Autoren sowie Ressourcen wie Wortlisten zusammen. Ein **Schreibkräfte-Pool** steht für ein Schreibteam. Eine Weiterleitungsregel verbindet beide. Beim Konto zeigt **Poolbezüge** die Mitgliedschaft, **Fachrechte** die individuell erlaubten Aktionen.

1. Suchen Sie den Autorenpool und prüfen Sie, welches Schreibteam seine Diktate erhält. Prüfen Sie vor einer Änderung die betroffenen Mitgliedschaften und ihre Gültigkeit.
2. Öffnen Sie mit einem berechtigten Teamkonto die Arbeitsliste. Die Poolleitung kann im zugewiesenen Team Aufträge verteilen. Kontrollieren Sie anschließend am Diktat den zugewiesenen Namen.
3. Prüfen Sie Sonderrechte einzeln. **Freigeben** gilt im erteilten Geltungsbereich. **Originalaudio exportieren** benötigt ein separates ausdrückliches Recht. Eine Leitungsrolle allein erteilt keines dieser Rechte.

Prüfen Sie vor dem Deaktivieren die angezeigte Nutzung. Die historischen Bezüge bleiben erhalten. Für das Anlegen von Autorenpools gibt es eine administrative API. Die normale Poolliste dient der Verwaltung bestehender Einträge. Die Freigabegruppen und gemeinsamen Schlagwörter des Upstream-Projekts erfüllen andere Aufgaben.
