# Schutz der Diktatdaten

[English](../../admin-guide/privacy.md)

Zu einem Diktat können mehrere getrennte Datensätze gehören: Originalaudio und Prüfsumme, Transkriptfassungen, generierte Zusammenfassung, Workflowverlauf, Importbelege und Ausgabeprotokoll. Beim Einsatz eines Importagenten können auch Inventar-, Übertragungs- und Empfangsdaten auf die Quelldatei verweisen. Beziehen Sie diese Speicherorte und ihre Sicherungen in das örtliche Berechtigungs- und Aufbewahrungskonzept ein.

Erteilen Sie nur die erforderlichen Pool- und Einzelrechte. Die Site-Administration kann einen protokollierten Lese- oder Wiedergabezugriff haben. Für Bearbeitung, Freigabe und Originalaudioexport gelten eigene Kontrollen. Verwenden Sie für Abnahmen, Testexporte und Support-Bilder eine neutrale synthetische Aufnahme. Halten Sie Diktatinhalte aus Kontonamen und Betriebsnotizen heraus. Die optionale [SMTP-Mitteilung](email-setup.md) kann den Aufnahmetitel aus der Anwendung übertragen.

Ein als BYOD eingestufter Browser erhält durch eine Serveranmeldung weder eine lokale Audiokopie für Offlinebetrieb noch einen Bündel-Export. Verwalteter Offlinespeicher ist vorbereitet und deaktiviert. Stimmprofile erfordern eine Einwilligung für die eigene Stimme des Autors. Prüfen Sie einen Widerruf im betreffenden Profil. Ein synthetischer Test zertifiziert weder ein Gerät noch einen Anschluss an ein klinisches System. Legen Sie Fristen und Zuständigkeiten betrieblich fest.
