# Klinikverwaltung

[English](../../admin-guide/index.md)

Öffnen Sie **Verwaltung**. Auf der Einstiegsseite **Benutzer und Rollen** finden Sie Kontodaten, Poolbezüge und gesonderte Fachrechte.

| Aufgabe | Einstieg |
| --- | --- |
| Konto nachschlagen, Zugriffe ändern, Poolzuordnung prüfen | **Konten und Pools** → [Konten](user-management.md) oder [Pools](group-management.md) |
| Gemeinsames Vokabular, Vorlagen und Regeln pflegen | **Inhalte** und **Richtlinien** |
| Importdateien, Verarbeitungsaufträge oder ASR-Profile prüfen | **Betrieb** |
| Einstellungen, Auditprotokoll oder verwendetes Modell prüfen | **System** → [Einstellungen](system-settings.md), [Audit](audit-log.md) oder [Modellwahl](model-configuration.md) |

**Die passende Rolle wählen.** Die allgemeine Administrationsrolle und die lokale Identitätsadministration haben unterschiedliche Aufgaben. Eine Poolleitung koordiniert die Arbeit im zugewiesenen Team. Für die Freigabe einer Fassung und den Export des Originalaudios sind eigene Fachrechte nötig. Ein protokollierter Lese- oder Wiedergabezugriff erteilt kein Bearbeitungsrecht. Meldet eine Seite fehlenden Zugriff, prüfen Sie mit der zuständigen Administration die Rolle und den Geltungsbereich der Berechtigung.

Für einen Versionswechsel lesen Sie die [Migrationsanleitung](migration-guide.md). Für die Aufbewahrung klinischer Informationen gelten die Hinweise zu [Archivierung](retention.md) und [Datenschutz](privacy.md).
