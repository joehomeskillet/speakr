# Webhooks

[English](../../admin-guide/webhooks.md)

Der Klinik-Fork bietet keine persönlichen Webhooks und keine Registrierung von Rückrufadressen. Eine übernommene Webhook-Einstellung aktiviert diese Funktion im Klinikmodus nicht. Workflow-Hinweise bleiben innerhalb der Anwendung; siehe [E-Mail und interne Hinweise](email-setup.md). Prüfen Sie für eine klinische Übergabe Ergebnis und Quittung in **Ausgabe**, statt eine Benachrichtigung als Zustellbeleg zu behandeln. Siehe auch das [Auditprotokoll](audit-log.md).
