# Webhooks

[English](../../admin-guide/webhooks.md)

Der Klinik-Fork bietet keine persönlichen Webhooks und keine Registrierung von Rückrufadressen. Webhooks sind kein Weg, Dokumente oder Benachrichtigungen ausserhalb des Klinikumfangs zu versenden. Eine übernommene Webhook-Einstellung aktiviert diese Funktion im Klinikmodus nicht. Benachrichtigungen bleiben innerhalb der Anwendung; siehe [Benachrichtigungen](email-setup.md). Siehe auch das [Auditprotokoll](audit-log.md).
