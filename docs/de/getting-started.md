# Das erste Diktat

[English](../getting-started.md)

Verwenden Sie die HTTPS-Adresse und das Klinikkonto Ihrer Administration. Für die Übung eignet sich ein Autorenkonto mit Schreibkräfte-Pool und Rechten zum Anhören und Bearbeiten eigener Diktate. Sie brauchen einen Browser mit Mikrofonzugriff oder eine kurze WAV-Datei.

1. Öffnen Sie **Neue Aufnahme**, geben Sie einen neutralen Titel ein und erlauben Sie den Mikrofonzugriff. Sprechen Sie zwei unterschiedliche Sätze und stoppen Sie die Aufnahme. Für eine vorhandene Datei öffnen Sie die Dateiauswahl und wählen eine nicht leere Audiodatei.
2. Sichern Sie den Entwurf. Warten Sie auf die Serverbestätigung, bevor Sie die Seite schließen. Um den Schreibauftrag zu starten, wählen Sie anschließend **Einreichen** und bestätigen den Schritt.
3. Suchen Sie den Eintrag unter **Aufnahmen** nach Zeitpunkt oder Kennung und öffnen Sie seinen Titel. Drücken Sie am **Schreibplatz** auf Wiedergabe. Prüfen Sie Zeitfortschritt und beide Sätze. Mit Pause und Rücksprung lässt sich ein einzelnes Wort vergleichen. Während der Ton bereits verfügbar ist, kann die Erkennung noch laufen.
4. Übernehmen Sie bei vorliegendem Transkript die Bearbeitung, falls erforderlich. Ändern Sie ein Wort, speichern Sie und kontrollieren Sie den Wortlaut nach erneutem Öffnen. Eine Statusänderung allein speichert keine Texteingabe.
5. Prüfen Sie den Arbeitsstand in der **Arbeitsliste**. Öffnen Sie die Kennung zum Gegenlesen mit einem passend berechtigten zweiten Konto. Freigabe und Dokumentausgabe benötigen eigene Befugnisse.

Fehlt ein Eintrag oder eine Schaltfläche, kontrollieren Sie Pool, Zeitraum, Arbeitsstand und Zuweisung vor einem erneuten Upload. Weitere Hinweise stehen in der [Fehlerdiagnose](troubleshooting.md).
