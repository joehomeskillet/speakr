# Speakr clinic handbook

[Deutsch](de/index.md)

Speakr takes a dictation from a browser microphone or audio file to a worklist, corrected text and a versioned release. Authors record, typists compare text with audio, and reviewers approve the specific revision they examined.

| Compare the web workflow with a desktop dictation system | [Features](features.md) and [remaining gaps](roadmap.md) |

The [gallery](screenshots.md) shows the working interface on a computer and a phone. For a first trial, use a short recording made for the test and an account restricted to the trial pool. Keep the recording identifier until you have heard the audio and reopened the saved text.
