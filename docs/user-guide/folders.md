# Organise work with lists and the archive

English · [Deutsch](../de/user-guide/folders.md)

Use **Aufnahmen** to browse visible dictations by recording date and filter by period or status. Its search covers the author, pool, case ID and dictation ID of loaded rows. In **Arbeitsliste**, use the assignment, priority and deadline columns to decide what needs work.

For archived workflow items, choose **Verwaltung & Seiten → Archiv**. Narrow the archive by date and, where available to your account, author or pool. Return to the main list for current work. A dictation can fall outside one filter while remaining visible in another permitted view.

Personal folder trees, shared folders and moving a recording into a folder belong to the upstream organiser. The clinic uses workflow state and authorised pool assignment. Changing a list filter changes the view only. [How pools work](groups.md).
