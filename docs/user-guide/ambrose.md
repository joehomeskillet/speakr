# Ambrose and a single dictation

English · [Deutsch](../de/user-guide/ambrose.md)

Ambrose is the assistant described in the original Speakr guide. The clinic workflow for verifying a statement starts with the dictation itself.

1. In **Aufnahmen**, open the authorised dictation. Check its author and case context.
2. Select **Diktat anhören** to replay the passage. If you can edit, choose **Im Schreibplatz öffnen** and compare the recognised wording with the audio.
3. Save an actual correction in **Schreibplatz** and check **Verlauf**. Generated wording or a chat answer cannot record a correction or a release decision on your behalf.

Local AI availability depends on the clinic deployment. The standard dictation screens do not require an assistant chat. For a question spanning several recordings, use the [list search](inquire-mode.md) to locate the source first.
