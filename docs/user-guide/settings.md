# Account and workstation settings

English · [Deutsch](../de/user-guide/settings.md)

Select your initials in the header. **Konto** opens the account page. **Einstellungen** opens the clinic workstation settings. Check the displayed account before changing preferences on a shared machine.

Under **Einstellungen**, **Herkunft der Werte** shows whether a value is personal, set centrally or limited centrally. In **Fußpedal (Tastaturmodus)**, associate a recognised key with a playback action and set the rewind or forward interval. Confirm the mapping first with a test dictation in the focused browser. A storage warning means the workstation preference has not been saved.

The voice-profile consent area shows the current decision and its history where available. Review consent separately from dictation rights. A personal preference cannot expand access to another pool, grant document release or change the local recognition service. For a missing account entitlement contact the clinic administrator.
