# Record, upload and submit

English · [Deutsch](../de/user-guide/recording.md)

## Record in the browser

1. Choose **Neue Aufnahme → Aufnehmen**. Enter a **Titel**. **Diktiert von** identifies the signed-in person.
2. Select **Aufnahme starten**. Allow microphone access for this clinic address when prompted. **Pausieren** interrupts capture and **Fortsetzen** continues it.
3. Select **Aufnahme beenden**. Use **Abspielen** to listen before transfer. The recording is still unsaved at this point.
4. Choose **Entwurf sichern** and wait for confirmation. Only then select **Einreichen** to hand the saved dictation to the writing service. Wait for **Eingereicht** before leaving.

## Use an existing audio file

Under **Neue Aufnahme → Datei hochladen**, select a non-empty audio file through the browser picker, then save and submit it as above. Keep the source file until the upload has been confirmed. If saving fails, use the retry on the existing form. If the microphone cannot start, check this site's browser permission and the selected input device.

**Aufnahmen** shows local recognition progress. The open list updates while processing is active. Real-time recognition during dictation and voice-triggered recording are separate capabilities. For the supported workflow, record first and check the transcript after recognition. [Review the result](transcripts.md).
