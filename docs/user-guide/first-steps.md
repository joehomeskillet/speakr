# First steps

English · [Deutsch](../de/user-guide/first-steps.md)

1. Open the clinic’s address in your browser and sign in with the account issued to you. If sign-in fails, contact your account administrator.
2. Open **Aufnahmen**. Use status and period to narrow the list. Its search matches the author, pool, case ID or dictation ID within **loaded rows**. Load more before concluding an item is missing.
3. Select the appropriate dictation. In **Diktatdetails**, check **Diktiert von**, **Schreibkräfte-Pool** and, where supplied, **Fall-ID**. Under **Diktat anhören**, play or pause the current audio. Playback requires separate permission.
4. Choose **Im Schreibplatz öffnen** to work on the transcript if you have editing rights. Use **Arbeitsliste** for assigned work. The dictation’s details distinguish processing, work, review and output status.

To create your first recording, start with a neutral test title and follow [Recording audio](recording.md). If the list is empty, clear its filters first. An administrator can check your account or assignment.
