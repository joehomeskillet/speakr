# Keyboard controls in the writing workspace

English · [Deutsch](../de/user-guide/keyboard-shortcuts.md)

Open an editable dictation in **Schreibplatz**. Place focus in the document, then press **F1** or use the **Tastaturhilfe** toolbar button to see the commands. On macOS use **Cmd** where the table shows **Ctrl**.

| Action | Keys |
|---|---|
| Save the current correction | Ctrl+S |
| Undo / redo a text edit | Ctrl+Z / Ctrl+Shift+Z |
| Insert a paragraph | Ctrl+Enter |
| Find within the transcript | Ctrl+F |
| Next / previous match in the search field | Enter / Shift+Enter |
| Toggle the editor’s full-screen mode | Ctrl+Shift+F |

In the dictation details, tab to the playback control and press Enter to play or pause. Use the focused waveform slider to seek. In a context dialog, Escape or the displayed close button returns focus to its opener. Editing shortcuts require a writable workspace. Undoing text is separate from undoing an audio cut.

A foot pedal in keyboard mode uses the browser’s focused key handling. Configure it in [workstation settings](settings.md). System-wide shortcuts used in other applications are outside the web client.
