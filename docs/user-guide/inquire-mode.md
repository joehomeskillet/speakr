# Find the dictation behind a question

English · [Deutsch](../de/user-guide/inquire-mode.md)

The upstream **Ask Ambrose** feature asks natural-language questions across indexed recordings. The clinic’s **Aufnahmen** search works on the metadata of the rows your account has loaded.

1. Open **Aufnahmen** and select a suitable period or processing status.
2. Search by author, writing pool, case ID or dictation ID. Load further rows if the list indicates that more are available. The search does not search the spoken words.
3. Open the matching item. Verify the case and use **Diktat anhören** to confirm the passage. Within the editable transcript use the **Schreibplatz** search to find a word.

An empty search can mean the row is filtered out, not loaded or outside your access. Your pool administrator can check the assignment. A search result does not authorise cross-case retrieval or grant additional playback rights.
