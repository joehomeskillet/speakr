# Listen, correct and review

English · [Deutsch](../de/user-guide/transcripts.md)

Open the dictation’s details and select **Diktat anhören**. Start playback and seek in the waveform. When waveform data is unavailable, use the browser’s audio controls. Both play the current audio revision. Someone else can hold the editing lease while you listen with your own playback permission.

## Correct a passage

1. Open **Im Schreibplatz öffnen**. Check the title and the editing status before typing. An active lease held by another person prevents concurrent editing.
2. Compare the passage with its audio. Where word timing exists, the player highlights the corresponding text. Newly inserted words or widely rewritten passages may have no reliable timing.
3. Edit the text, choose **Speichern** and wait for confirmation. If the server reports a newer version, compare it with your changes before deciding which text to keep.
4. Use **Verlauf** to check the resulting version. If authorised to edit audio, a cut, insertion or overwrite creates a new audio revision. A subsequent recognition request operates on the current cut. The original and human corrections retain their revision history.

**Prüfen und Freigeben** records a separate workflow decision. Check the current text, audio and case context there. Completed recognition alone does not release a document.
