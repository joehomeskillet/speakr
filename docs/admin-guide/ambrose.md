# What replaces Ambrose in the clinic workflow?

[Deutsch](../de/admin-guide/ambrose.md)

The upstream Ambrose assistant offers recording chat and a separate Ask view. The clinic workspace has no Ambrose button, chat panel or cross-recording Ask screen. Changing the assistant name or enabling an upstream inquiry option does not add these controls.

For a question about one dictation, open it from **Aufnahmen** or the worklist. Listen to the relevant passage, compare its transcript and open **KI-Zusammenfassung** when a concise account is needed. A generated summary relates to the saved dictation text; it is not a search across other people's recordings. A user who needs a different model or a missing local text service should contact the site administrator.

Some per-recording API capabilities depend on an explicitly local text model. Their presence is distinct from having an assistant in the clinic interface. See [local models](model-configuration.md) and [vector search](vector-store.md).
