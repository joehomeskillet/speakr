# Webhooks

[Deutsch](../de/admin-guide/webhooks.md)

The clinic fork does not offer personal webhooks or callback registration. An inherited webhook setting does not enable this feature in clinic mode. Workflow notices stay inside the application; see [email and internal notices](email-setup.md). For a clinical delivery, check the outcome and receipt in **Ausgabe** (output), rather than treating a notification as a delivery receipt. See also the [audit log](audit-log.md).
