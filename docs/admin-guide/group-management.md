# Author pools and writing teams

[Deutsch](../de/admin-guide/group-management.md)

Use **Verwaltung → Konten und Pools** to find the right team. An **Autorenpool** groups authors and pool resources such as vocabulary. A **Schreibkräfte-Pool** represents a writing team. Routing connects the two. The **Poolbezüge** tab of an account and its **Fachrechte** answer different questions: team membership and the actions an individual may take.

1. Look up the author pool and check which writing team receives its dictations. Check the affected memberships and any validity dates before changing a route.
2. Open the writing team's worklist as an authorised team member. A pool lead can coordinate assignments within the routed team. Confirm the assigned name on the dictation.
3. Check each exceptional permission separately. **Freigeben** authorises the release step within its scope. **Originalaudio exportieren** requires its own explicit grant. Neither follows from a leadership title.

Use the usage preview before deactivating a pool. Keep its historical references intact. Creating author pools is an administrative API capability; the ordinary pool list does not promise a creation form. Upstream sharing groups and shared tags are separate concepts.
