# Your first dictation

[Deutsch](de/getting-started.md)

Use the HTTPS address and clinic login issued by your administrator. For this exercise, ask for an author account with a writing pool and permission to play and edit its own dictations. A browser with microphone access is sufficient. A short WAV file is an alternative.

1. Open **Neue Aufnahme** (new recording). Enter a neutral title and allow the microphone when prompted. Record two different sentences and stop. For a file, use the audio file picker and select a non-empty file.
2. Save the draft. Wait for the server confirmation before closing the page. A saved draft and a submission to the worklist are separate actions. Choose **Einreichen** and confirm when you want the writing workflow to start.
3. In **Aufnahmen**, find the entry by time or identifier and open its title. In **Schreibplatz**, press Play, check that the time advances and listen for both sentences. Pause or step back to verify a word. Automatic recognition can still be running when playback is available.
4. Once the transcript is ready, take the edit lease if required. Change one word, save, then reopen the recording and check the saved wording. A change to the workflow status alone does not save typed text.
5. Open **Arbeitsliste** to check the new work status. With a second, appropriately scoped account, reopen the same identifier and verify the expected actions. Release and document output require their own permissions.

If the item or a button is missing, check the selected pool, date range, workflow state and your assignment before repeating the upload. See [troubleshooting](troubleshooting.md).
